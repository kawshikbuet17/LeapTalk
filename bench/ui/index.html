Configurations

10 Bangla TTS clips (OmniVoice outputs), 512×512 @ 25 fps, 1 NFE, bf16, after warmup. RTF = compute time ÷ audio duration (<1 is faster than real-time). TTFA = time from audio stream start (audio arriving at 1× speed) to the first chunk: frames = raw frames on host, A/V = encoded playable fMP4 (encode overlapped with next chunk), demo-serial = official web-demo path (compute then encode in one thread). All include the 1.12 s chunk buffer. Stall = playback had to wait for a chunk.
